# 第十五步：warm-up后动态融合训练至300轮

只训练一条新动态模型路线，不再重复300轮等权基线。

## 训练过程

1. 使用全部18,750个官方训练样本进行等权warm-up，动态门关闭。
2. 同时训练三个辅助分类头、原公式16和三个显式正确性头 `q`。
3. 保存第30轮和第50轮的模型、优化器、学习率调度器完整状态。
4. 如果31–50轮的最高验证OA相比1–30轮不足0.1个百分点，则从第30轮切换；否则从第50轮切换。
5. 开启梯度平衡的 `q`-CoRiM/FW，只加权Transformer 1收到的纯模态输入，继续训练至总epoch=300。

原始三个残差、Transformer 2以及最终三分支等权求和均保持不变。

## 动态方式

单模态辅助概率产生显式正确概率 `q`。CoRiM基础梯度与 `-log(q)` 的模态梯度差在等权点进行逐样本尺度平衡，冲突门控保留。FW参数沿用前序审计：`alpha=1, beta=0.25, gamma=64, T=10, lambda_q=0.05`。

## 可续跑

`warmup_latest.pt` 和 `dynamic_latest.pt` 每轮保存模型、优化器和调度器状态。进程中断后使用相同命令即可继续，不会从头重训。

验证仍使用此前固定的每类200诊断子集，以便和已有三模态实验直接比较。由于该子集来自官方测试标签，最终结果必须注明这一来源，不能作为完全干净的论文测试。
