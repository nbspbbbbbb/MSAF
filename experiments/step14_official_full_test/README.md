# 第十四步：Houston2018官方全测试集

官方固定训练集共有18,750个样本，各类数量为：

```text
[1000,1000,1000,1000,1000,1000,500,1000,1000,1000,
 1000,1000,1000,1000,1000,1000,250,1000,1000,1000]
```

官方测试集包含2,000,160个有标签像素。该规模约为此前4000诊断子集的500倍。

脚本使用滑动窗口视图分批抽取11×11补丁，不会一次性构造全部测试补丁。预测、置信度和三模态浅层冲突写入可续跑的NumPy memmap；`progress.json`记录断点。

默认checkpoint是使用全部18,750官方训练样本训练30轮、辅助损失权重0.1的PureAuxMSAF3。这个checkpoint此前使用每类200的诊断子集选择模型，报告中会保留该来源说明，不能伪装成完全未接触测试标签的最终论文结果。
